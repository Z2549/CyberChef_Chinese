        某项功能是如何工作的？

        CyberChef 具有上下文帮助功能。把光标悬停在您想了解更多的地方，然后按键盘上的 F1，即可看到相关说明。现在就把光标悬停在这段文字上并按一下 F1 试试吧！


        我可以用 CyberChef 做什么？

        CyberChef 中有 数百个操作，让您轻松完成简单与复杂的任务。以下是一些示例：

        • 解码 Base64 编码的字符串
        • 把日期时间转换为其他时区
        • 解析 Teredo IPv6 地址
        • 从十六进制转储转换数据，然后解压
        • 解密并反汇编 shellcode
        • 把多个时间戳显示为完整日期
        • 对不同类型的执行不同操作
        • 把输入的一部分作为操作的参数

        我可以直接从文件加载输入吗？

        可以！只需把文件拖放到输入框上即可。

        CyberChef 可处理约 2GB 以内的文件（取决于浏览器），但某些操作在处理如此大量的数据时可能运行得非常慢。

        如果输出超过某个阈值（默认 1MiB），会以可下载文件的形式提供。如需查看，可在输出中浏览文件的分片。


        如何一次性对多个输入运行某个操作？

        比如您有 10 个想解析的时间戳，或者 16 个使用同一密钥的编码字符串。

        “Fork”操作（位于“流程控制”类别中）会按行拆分输入，并对每一行分别运行后续的所有操作，每行输出显示为独立的一行。这些分隔符可以更改，因此如果您的输入以逗号分隔，可以把拆分分隔符改成逗号。

        点击此处查看示例。


        “Magic”操作是如何工作的？

        “Magic”操作使用多种方法检测编码数据，以及可用于解读这些数据的操作。这些方法的技术说明见此处。

        是什么
        
                                
        一个简单直观的网页应用，无需复杂工具或编程语言即可分析和解码数据。CyberChef 鼓励技术与非技术背景的人一同探索数据格式、加密与压缩。

        

                                
        为什么
        
                                
        当今世界的数字数据形态、大小和格式各异 —— CyberChef 帮助您在一个易用的平台上理解这些数据。

        


                                
        怎么做
        
                                
        界面设计以简洁为核心。过去复杂的技术如今只是拖放而已。简单的函数可以组合成“配方”，进而实现复杂的分析，并与其他用户分享、配合他们的输入使用。
        
                                
        对于习惯写代码的人，CyberChef 是快速高效地原型化解决方案的方式，验证可行后即可脚本化。

        


                                
        适用于谁
        
                                
        CyberChef 预计对网络安全与反病毒公司很有用，也应能吸引学术界以及任何从事数字数据分析的个人或公司，无论是软件开发者、分析师、数学家，还是偶尔解谜的爱好者。

        


                                
        目标
        
                                
        希望通过在 GitHub 上发布 CyberChef，能汇集各方贡献并应用到该工具的未来版本中。

        


                                
        
                                
        无论是想把时间戳转换成其他格式、解压 gzip 数据、生成 SHA3 散列，还是解析 X.509 证书以查明签发者，CyberChef 都提供了 数百个有用的操作，适合任何与互联网相关的工作。
        
                                
        它就是网络瑞士军刀。

            下载 CyberChef
            
                    
            
                    
            
                        
            
                            CyberChef 完全在您的浏览器中运行，没有服务端组件。这意味着无论在线的官方版本，还是下载的独立版本（未被修改的前提下），您的输入数据和配方配置都不会被发送到任何地方。
                        
            
                        
            
                            有三个操作会调用外部服务，分别是：从 wikimedia.org 下载地图瓦片的“Show on map”操作、使用 Google 或 Cloudflare 服务解析 DNS 请求的“DNS over HTTPS”操作，以及向您填写的 URL 发起请求的“HTTP request”操作。您可以使用浏览器开发者控制台（F12）的“网络”标签页确认发起了哪些网络请求。
                        
            
                        
            
                            如果您希望下载一份独立的 CyberChef 副本，以便在隔离网络或网络受限、无网络连接的环境中使用，可以在下方获取包含整个网页应用的 ZIP 文件。它可以本地运行，也可以直接托管在 Web 服务器上，无需任何配置。
                        
            
                        
            
                            请注意，独立版本不会自动更新，也就是说在您手动重新下载新版本之前，它不会获得缺陷修复或新功能。
